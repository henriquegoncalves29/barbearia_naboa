# Barber Style - Agendamento

Sistema de agendamento online para barbearia.

## Funcionalidades
- Escolha de serviços.
- Escolha de barbeiros.
- Seleção de datas.
- Seleção de horários.
- Formulário de agendamento.
- Confirmação de agendamento.

## Tecnologias
- HTML5
- CSS3
- JavaScript
